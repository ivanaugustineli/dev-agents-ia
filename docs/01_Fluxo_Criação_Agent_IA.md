# Fluxo de Criação de Agentes de IA

## 1 - Preparação do Ambiente

### 1.1 - Linguagem Python
Como linguagem de programação vamos utilizar o Python (maior biblioteca de linguagem de desenvolvimento para IA que existe).

### 1.2 - UV
Utilizaremos como instalador para Python, o UV (https://docs.astral.sh/uv/) maior e mais rápida que o pip e as demais ferramentas.

- Instalado em Linux Ubuntu (direto ou WSL no Windows)
~~~bash
curl -LsSf https://astral.sh/uv/install.sh | sh
~~~

- Instalado em Windows PowerShell
~~~bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
~~~
